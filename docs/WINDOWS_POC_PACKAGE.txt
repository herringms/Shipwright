Hyrule Co-op Proof of Concept 2 - Windows

This package contains the same Shipwright executable and support files for both players. Its minimal configuration
selects the verified OpenGL renderer; Shipwright fills in normal controller and preference defaults on first launch.

Players normally start HyruleCoop.exe from the bootstrap package, not soh.exe in this runtime directory. The
launcher installs and verifies this complete runtime under %LOCALAPPDATA%\HyruleCoop\Runtime, then starts it with
%LOCALAPPDATA%\HyruleCoop\UserData as the working directory.

On first launch, the launcher can copy an existing generated oot.o2r from a recognized nearby Shipwright
installation, or the player can choose their own supported Ocarina of Time ROM. Copying a ROM into AppData is a
separate explicit choice. The included extractor-assets.zip is the open-source extractor definition payload;
Shipwright reads it directly without unpacking thousands of manifest files beside the game.

First launch creates or expands shipofharkinian.json, may create logs and mods folders, and can generate oot.o2r
from the player's ROM. Generated assets, settings, mods, and logs remain under
%LOCALAPPDATA%\HyruleCoop\UserData. Saves remain under %LOCALAPPDATA%\HyruleCoop\Save.

The package intentionally does not contain a ROM, generated oot.o2r, save files, controller settings, logs, or test
configuration. Do not add a ROM or generated O2R archive when sharing this package.

The launcher can copy saves from a nearby legacy portable installation into AppData without deleting the
originals. Runtime updates never manage or replace the player's O2R, ROM, saves, configuration, mods, or logs.

To play:
1. Start HyruleCoop.exe and complete the one-time existing-installation or ROM prompt.
2. Let the launcher verify the runtime and start Shipwright, then load a save.
3. Open Enhancements > Network > Direct Co-op.
4. The host chooses a private port and selects Host Game.
5. The guest enters the host address and matching port, then selects Join Game.

Both players must use this exact package. The handshake rejects a different Hyrule Co-op compatibility build.

For later releases, start the same HyruleCoop.exe. It checks the latest published GitHub Release, downloads and
verifies a complete managed runtime, and switches versions only after validation. Git and a GitHub account are not
required. The previous verified runtime remains available for rollback.

Proof 2 shares durable inventory and equipment while preserving each player's currency, ammunition, current health
and magic, and bottle contents. The current synchronized gameplay adapters are Deku Baba and Queen Gohma.
